# AI 工作流

AI 在工作上的應用 — 兩個方向：**AI 寫程式**（Claude/Cursor 怎麼指揮）與 **PM 用 AI 生產文件**（PRD/MRD/研究計畫等的 prompt 模板）。

## 📁 兩大子主題

### AI Coding 工作流（7 卡）

給 AI 寫程式工具（Claude Code / Cursor / Antigravity 等）的協作規則與 5 個 slash command workflow（/research / /refactor / /feature-dev / /decision / /bug-fix）。

- 📄 AI Global Rules
- 📄 Vibe Coding 協作規則
- 📄 5 個 Workflow! slash commands

### PM Prompt 模板（16 卡）

PM 工作時用 AI 產出標準文件的 prompt 模板。涵蓋：
- **產品文件類**：PRD、MRD、Prompt 設計文件、產品指標追蹤、產品成長假設、功能優化迭代、WBS 拆分
- **用戶研究類**：用戶研究計畫、用戶洞察萃取、需求本質探索、需求假設驗證、競品定位
- **資料分析類**：探索性資料洞察、數據決策驗證、投資研究、跨領域產業公司分析

## 用法

- 寫 PRD → 從 `PM Prompt 模板/產品需求文件 (PRD).md` 拉內容貼進 ChatGPT/Claude
- 用 Cursor 重構 → 走 `AI Coding 工作流/Workflow! Refactor.md` 的步驟
- 設定 AI 工具一次性規則 → 用 `AI Coding 工作流/AI Global Rules.md`
